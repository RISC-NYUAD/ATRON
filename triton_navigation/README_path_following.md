# Path Following Controller

This implements a Pure Pursuit controller for differential drive robots to follow paths generated by the path planner.

## How It Works

1. **Subscribes to**:
   - `/planned_path` - The path to follow (from path planner)
   - `map → base_link` transform - Current robot position

2. **Publishes to**:
   - `/cmd_vel` - Velocity commands for the robot

3. **Algorithm**:
   - Uses Pure Pursuit to find a lookahead point on the path
   - Calculates angular velocity to steer toward that point
   - Adjusts linear velocity based on turning sharpness
   - Slows down when approaching the goal

## Usage

### Launch with path planner:
```bash
ros2 launch triton_navigation navigation_with_controller.launch.xml
```

### Launch controller only:
```bash
ros2 launch triton_navigation path_following.launch.xml
```

### Parameters (in config/path_following.yaml):
- `lookahead_distance`: How far ahead to look (default: 0.5m)
- `max_linear_velocity`: Maximum forward speed (default: 0.5 m/s)
- `max_angular_velocity`: Maximum turning speed (default: 1.0 rad/s)
- `goal_tolerance`: Distance to consider goal reached (default: 0.1m)

## Testing

1. Start your localization system (SLAM or AMCL) to provide `map → base_link` transform
2. Launch the path planner and controller
3. Set a goal using:
   ```bash
   ros2 topic pub /goal_pose geometry_msgs/PoseStamped "{header: {frame_id: 'map'}, pose: {position: {x: 2.0, y: 1.0}, orientation: {w: 1.0}}}" --once
   ```
4. The robot should plan a path and follow it to the goal

## Tuning Tips

- **Robot oscillates**: Reduce `angular_velocity_gain`
- **Robot overshoots turns**: Reduce `lookahead_distance`
- **Path following too loose**: Increase `angular_velocity_gain` or reduce `lookahead_distance`
- **Robot moves too fast**: Reduce `max_linear_velocity`
